# Coding Practice

> A private record of problem-solving practice. The goal is consistency, reflection, and gradual improvement — not collecting perfect solutions.

## What belongs here

- Exercises from platforms such as LeetCode, beecrowd, HackerRank, Neps Academy, and Exercism.
- Revisited solutions when I learn a clearer or more efficient approach.
- Short notes about recurring patterns, mistakes, and useful ideas.

## Suggested structure

```text
platforms/
├── beecrowd/
├── exercism/
├── hackerrank/
├── leetcode/
└── neps-academy/

notes/
└── patterns.md
```

Create a platform folder only when the first exercise from it is added. Inside each platform, organize files by language or problem set whenever that becomes useful.

## A good solution entry

Keep each solution lightweight. Include the source link and a short note about the main idea in a comment or adjacent Markdown file when it helps future-you understand it.

## Status

**Active.** Small, consistent practice belongs here — unfinished streaks and imperfect solutions are welcome.
